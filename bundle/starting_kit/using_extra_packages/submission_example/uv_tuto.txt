Example of submission files with extra Python packages
--------------------------------------------------------------------------
This file shows how to include extra Python packages in your submission
and how to use them in your submission files.

This TUTORIAL WILL ONLY WORK WITH LINUX!

This type of installation is suitable for small packages that do not
require compilation, or git-installable packages such as gromo (the
package the provided gromo solution depends on).

--------------------------------------------------------------------------
IMPORTANT: Make sure that the extra packages you include are compatible
with the Python version and the packages already installed in the
Codabench environment. This competition's environment uses Python 3.12
(see the docker_image entry in competition.yaml). ../requirements.txt lists
the same packages as ../environment.yml (the conda version, for conda_tuto.txt)
but by their pip/PyPI names, for use with uv/pip instead.
--------------------------------------------------------------------------

To include extra Python packages, you need to:
0) Create a fresh environment based on the Codabench environment.
   We recommend using uv to create the environment you will install the
   packages into. From this folder:
   uv venv --python 3.12
   source .venv/bin/activate
   uv pip install -r ../requirements.txt
1) Create a folder named `python_packages` in the same directory as your
   nas.py / data_processor.py / trainer.py / helpers.py submission files.
2) Install the packages you need into that folder with --no-deps, then
   separately install any of THEIR dependencies that aren't already in the
   Codabench base image (see ../requirements.txt for what's already there).
   --no-deps avoids re-bundling torch/numpy/etc., which would bloat your zip
   and can conflict with the versions already in the Codabench environment.
   uv pip install --target PATH_FOR_YOUR_FOLDER/python_packages --no-deps <package_name>
   # e.g. for gromo (a working example of this is the provided `solution/`):
   uv pip install --target PATH_FOR_YOUR_FOLDER/python_packages --no-deps "git+https://github.com/growingnet/gromo.git@main#egg=gromo"
   uv pip install --target PATH_FOR_YOUR_FOLDER/python_packages --no-deps torchmetrics lightning-utilities tomli deprecated wrapt
3) Test locally that your submission works with the extra packages, e.g. via
   the starting kit Makefile (`make submission=YOUR_FOLDER all`). You will
   need to add the `python_packages` folder to your PYTHONPATH / sys.path
   for it to be importable -- add this near the top of nas.py (or wherever
   you import the extra package):
       import sys, os
       sys.path.append(os.path.join(os.path.dirname(__file__), "python_packages"))
4) Zip the `python_packages` folder along with your submission files (this is
   important!!!!!) and any other files you need (e.g., model weights) into a
   single zip file:
   (cd PATH_FOR_YOUR_FOLDER && zip -r ../submission.zip .)
   Only zip what is needed for your submission to run.
   DO NOT zip the entire PROJECT or any unnecessary files.
5) Upload the zip file to Codabench.


Note that the `python_packages` folder can be large depending on the
packages you install. Make sure to check the size of your zip file before
uploading it to Codabench.
