# MLflow Configuration (`mlflow/`)

Defines MLflow experiment tracking settings.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `experiment_name` | str | `"debug"` | MLflow experiment name. Runs are grouped under this name in the MLflow UI. |
| `tracking_uri` | str | varies | MLflow tracking URI. Can be a local file path (`file:./mlruns`) or a remote server URL. |
| `run_name` | str \| null | `null` | Name for the MLflow run. `null` = auto-generated by MLflow. Can use Hydra interpolation (e.g., `"fogro_${general.seed}"`). |
| `log_system_metrics` | bool | `true` | Log system metrics (CPU, GPU, memory usage) during the run. |

## Available Configs

| Config | Tracking URI | Description |
|--------|-------------|-------------|
| `default.yaml` | `file:./mlruns` | Local MLflow storage in the current directory |
| `iceberg.yaml` | `file:${oc.env:HOME}/tau_frugal/${oc.env:USER}/mlruns` | Shared storage on iceberg/titanic/margaret clusters |

## Logged Information

The pipeline automatically logs to MLflow:
- All Hydra config parameters (flattened)
- Git commit and branch info
- SLURM job ID and node name
- Device info (GPU name, index)
- Per-step metrics: train/val/test loss and accuracy
- Best validation/test accuracy
- Model checkpoints (best and final)
- Training log file
- Full Hydra config as YAML artifact
